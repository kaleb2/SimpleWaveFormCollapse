# Wave Form Collapse Testing

This is a play ground application for understanding wafe form collapse algorithm

## Run 

Supply three arguments:
1. The x coordinate of the first tile placed [1, 5]
2. The y coordinate of the first tile placed [1, 5]
3. The color of the first tile placed [r, g, b]

```python
python wfc.py 3 3 r
```
